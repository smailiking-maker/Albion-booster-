# Albion Boost (Android)

Простой VPN-клиент в стиле LagX для **Albion Online** (`com.albiononline`).

## Важно: как получить готовый APK-файл на телефон

Из браузера нельзя напрямую скачать готовый `.apk`, но вы можете получить его двумя способами:

### Способ 1 — Без установки программ на ПК (через GitHub за 2 минуты)
1. Создайте бесплатный репозиторий на GitHub и загрузите туда все файлы из этой папки (включая скрытую папку `.github/workflows/build-apk.yml`).
2. Откройте вкладку **Actions** → **Build AlbionBoost APK** → нажмите **Run workflow**.
3. Через 2 минуты внизу страницы появится артефакт **AlbionBoost-APK** — скачайте и установите `.apk` на Android.

### Способ 2 — Через Android Studio на компьютере
1. Откройте эту папку в **Android Studio**.
2. Дождитесь синхронизации Gradle.
3. Нажмите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. Заберите файл `app/build/outputs/apk/release/app-release.apk` и перекиньте на телефон.

## Как подключить рабочий сервер
1. Откройте приложение **Albion Boost** на телефоне.
2. Выберите город (например, **Амстердам**) и вставьте готовый текст из файла `.conf` (WireGuard).
   - Если у вас ещё нет `.conf`, арендуйте любой VPS в Амстердаме/Франкфурте и выполните на нём скрипт `server-setup/setup-eu-node.sh 443` — он сразу выдаст готовый текст для вставки.
3. Нажмите **«Подключиться»** и заходите в Albion Online.
